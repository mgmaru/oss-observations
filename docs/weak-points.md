# 自分の課題リスト

観察メモへのレビューや振り返りで見つかった、自分の読み方・書き方・運用の課題をまとめる。1回の観察だけの指摘ではなく、次のOSSでも繰り返しそうなものを残す。個別の指摘は、各対象の `reviews/` にあるレビューを参照する。

## 使い方

- 観察を始める前に、状態が「対応中」の課題と対策を読む。
- レビューを受けたら、新しい課題を追加する。すでにある課題が再び指摘されたら、「再発」にそのレビューへのリンクを追加する。
- 続けて2回の観察で指摘されなかった課題は、状態を「解消」にする。
- 4つのOSSを観察した後の振り返り（[運用ルール](../RULES.md)の「8. ルールの見直し」）で、再発の多い課題と対策を見直す。
