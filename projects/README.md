# 観察対象の一覧

対象ごとの記録と所要時間をまとめる。対象の登録方法は [トップのREADME](../README.md)、時間の扱いは [運用ルール](../RULES.md)を参照する。

## 対象

対象を決めたら、次の表に1行追加する。tidwall/gjsonは問いの候補を用意した段階で、観察は未着手。

| OSS | 主な観察範囲 | 初回（分） | 再訪（分） | 状態 | 記録 |
| --- | --- | --- | --- | --- | --- |
| tidwall/gjson | 設定値・modifierの流れ、共有状態とAPIの扱い | 0 | 0 | 未着手 | [問いの一覧](tidwall-gjson/README.md) |

状態は「未着手」「初回観察中」「初回完了」「再訪中」「再訪完了」で記録する。「記録」には対象ごとのREADMEへのリンクを付ける。

初回・再訪の時間は、観察メモの所要時間を合算した値。同じOSSの合計は、その2つの列を足した時間になる。初回を早く終了しても、再訪の上限は90分。

## 再訪枠

| 項目 | 現在の数 |
| --- | --- |
| 初回観察を終えた異なるOSS | 0 |
| 再訪枠の総数（上の数 ÷ 4 の整数部分） | 0 |
| 使用した再訪枠 | 0 |
| 残りの再訪枠 | 0 |

初回の記録を残して終了したら数を更新する。再訪する対象を選んだら、枠を使用済みにして、対象のREADMEに再訪の問いと理由を記載する。
